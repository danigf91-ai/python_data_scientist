# IBM Applied Data Science Capstone - SpaceX

This folder contains the deliverables for the IBM Applied Data Science Capstone project on predicting Falcon 9 first-stage landing success.

## Completed project components

- SpaceX API data collection and parsing with `requests` and `pd.json_normalize`
- Web scraping with `BeautifulSoup`
- Data wrangling, missing-value treatment and landing `Class` label creation
- Exploratory data analysis with Pandas/Seaborn
- SQLite EDA queries
- Folium launch-site and proximity analysis
- Plotly Dash interactive dashboard
- Classification with Logistic Regression, SVM, Decision Tree and KNN using GridSearchCV

## Python application

- `spacex-dash-app.py` - completed Plotly Dash dashboard with launch-site dropdown, payload range slider, success pie chart and payload-vs-outcome scatter plot.

## Final report

The submitted PDF presentation is titled `Data Science Capstone Project Report` and documents the full workflow, results, conclusion and innovative insights.
